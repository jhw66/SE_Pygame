# 补充批次：检查死锁、生成随机可解题目

## 1. 本次确认的实际问题

旧固定棋盘共有 13 个箭头，按合法规则消除 7 个后还剩 6 个。
其中四个箭头形成循环阻挡，以下行列从 1 开始：

```text
(1,3) 向右，被 (1,5) 阻挡
(1,5) 向下，被 (3,5) 阻挡
(3,5) 向左，被 (3,3) 阻挡
(3,3) 向上，被 (1,3) 阻挡
```

这个环里没有任何箭头能够先出去，另外两个剩余箭头也被它们挡住。
这不是玩家选错了消除顺序。基础规则下，消除只会减少阻挡，不会制造新的阻挡。

此前测试覆盖了单个箭头的检测、动画、失败和重开，但没有检验整盘能否清空。
当时补齐了这个遗漏，并用旧棋盘作为已知无解案例进行检查；相关测试脚本现已移除。
实际游戏不再使用旧布局。

## 2. 两个按钮各自做什么

| 操作 | 结果 |
| --- | --- |
| 启动程序 | 随机生成 5×5、13 个箭头的新题，四方向齐全 |
| 重新开始 | 恢复当前题的初始布局，重新给 3 次机会 |
| 换一题 | 生成与上一题占位布局不同的新题，并重置状态 |
| 完全清空 | 显示本题通关，可换题或重玩 |

区分两个按钮，是为了同时满足“新鲜题目”和作业要求的“恢复当前关卡初始状态”。
同一次运行中换题保证相邻题目不同；跨程序启动不保存题目历史，因此不承诺永不重复。

INITIAL_BOARD 现在表示“当前题的初始快照”。启动时生成一次，换题时替换它，
重新开始时仍逐行复制这个快照。

## 3. 如何检查整盘可解

game_logic.py 新增 solve_board(board)：

1. 复制棋盘，不修改输入。
2. 找到一个当前可以飞出的箭头。
3. 删除并记录其坐标，继续寻找。
4. 全部清空就返回坐标顺序；仍有箭头却没有合法动作，返回 None。

空棋盘的答案是 []，无解是 None，二者含义不同，所以用 `is None` 判断无解。

本规则不需要回溯：删除箭头不会让其他箭头增加阻挡，因此可以直接选取一个合法动作。
这个结论来自本作业的“只能删除、不会生成或移动剩余箭头”的规则；增加机关后需重新分析。

## 4. 随机题目为什么可解

生成代码在 levels.py 的 generate_level()，采用先构造合法消除顺序的方法。

1. 在 25 个格子中随机抽出 13 个不同位置。
2. 用工作棋盘记录这些占位格，暂不确定最终方向。
3. 选择一个方向，从尚未移除的格子中找出沿这个方向能直接出去的候选。
4. 随机挑选一个候选，把位置和方向写入结果棋盘，再从工作棋盘移除。
5. 重复到所有占位格都移除；结果棋盘就是玩家看到的题目。

为什么候选不会为空？沿任意方向，都至少有一个最外侧的占位格可以朝外出去。
为什么最终可解？第一个选中的箭头在完整占位布局中就能出去；移除它后，第二个就能出去，
以此类推。其他箭头具体朝哪边不影响它是否构成阻挡，所以临时占位方向不破坏这个推导。

前四步优先使用还未选过的方向，因此四种方向都有。
如果抽出的占位位置恰好与上一题相同，移动其中一个到空格，保证换题确实改变布局。
生成完成后再调用 solve_board() 复核完整棋盘。

这是构造保证，1000 次随机测试是额外检查，不是用有限测试替代可解性的理由。
当前没有设定固定难度，随机题之间的难易可能不同。

## 5. 新学的随机函数

```python
positions = rng.sample(cells, arrow_count)
direction = rng.choice(unused_directions or list(DIRECTIONS))
```

- sample：从格子列表中抽出指定数量的位置；因为 cells 的元素不重复，所以抽出的格子不会重叠。
- choice：从候选列表中随机选取一个元素。
- `unused_directions or list(DIRECTIONS)`：还有没用过的方向就优先选它们，否则从全部方向选。
- 测试中使用 `random.Random(17)` 固定随机种子，方便复现同一道题；正常游戏不固定种子。

学习资料：[Python 官方 random 文档：序列用函数](https://docs.python.org/zh-cn/3/library/random.html#functions-for-sequences)。

## 6. 通关发生在动画结束以后

最后一个箭头完全离开、对应格子清空后才检查通关。当前实现位于 game_state.py：

```python
if not self.board.arrows:
    self.state = WON
```

WON 状态显示绿色通关标题，屏蔽棋盘点击，但允许重开与换题。
不能在最后一个箭头刚被点击时就通关，因为它还在棋盘里播放动画。
换题复用 reset_game()，因此失败、飞出、碰撞反馈均会一并清理。
