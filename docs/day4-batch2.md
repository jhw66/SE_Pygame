# 第四天 · 第二批：碰撞变红与计时恢复

本批继续使用 feat/day4-animation 分支，基于第一批飞出动画实现。
本批只增加碰撞变色，不提前加入第三批失败状态整理或第四批重新开始按钮。

## 1. 运行后观察什么

在项目根目录执行：

```powershell
.\.venv\Scripts\python.exe main.py
```

点击第 1 行第 3 列的向右箭头，它右边还有箭头，所以不能消除。
此时箭头变红、失误机会从 3 减为 2；约 0.25 秒后恢复青绿色，布局和数量不变。
黄色边框仍表示选中的格子，红色则表示短暂碰撞，两者分别记录。

## 2. 用两个变量表示短暂反馈

```python
collision_cell = None
collision_remaining = 0.0
```

- collision_cell：哪一格需要变红；None 表示没有正在显示的碰撞反馈。
- collision_remaining：还需要变红多少秒。

受阻点击分支中：

```python
collision_cell = (row, col)
collision_remaining = COLLISION_DURATION
mistakes_remaining -= 1
```

COLLISION_DURATION 当前为 0.25，单位为秒。
一次有效受阻点击只在这里扣一次机会，倒计时不扣机会。

## 3. 每帧减少剩余时间

```python
if collision_cell is not None:
    collision_remaining = max(0.0, collision_remaining - dt)
    if collision_remaining == 0:
        collision_cell = None
```

沿用第一批的 dt，它表示距离上一帧经过的秒数。
例如 0.25 秒减去一帧的 0.016 秒，剩下 0.234 秒。
max(0.0, ...) 表示取两个数中较大的一个，使倒计时最低为 0，避免减成负数。
因此后面可以检查是否等于 0；若没有这个截断，直接反复减小数并判断等于 0 可能错过结束。

更新放在每帧的事件处理之前：dt 对应已经经过的时间；处理新点击时才设置新的完整时长。
恢复颜色发生在倒计时首次归零的那一帧，因此可见时长约为 0.25 秒，受帧间隔影响。

这段更新不依赖新的点击，也不要求还有失误机会。
所以不再点击也会恢复；第三次失误导致失败后，最后的红色反馈仍正常结束。
窗口一直继续处理事件，没有使用 sleep 暂停程序。

## 4. 让绘图函数接受颜色参数

原来的 draw_arrow 总是使用 ARROW_COLOR，现在改成：

```python
def draw_arrow(surface, cx, cy, direction, color=ARROW_COLOR):
```

这叫默认参数：不传 color 时使用正常颜色；需要红色时额外传入 ERROR_COLOR。
函数内绘制线段和三角形都改为使用 color，确保箭杆与箭头颜色一致。
飞出动画原有的调用没有额外传颜色，所以仍使用正常颜色。

遍历棋盘时选择颜色：

```python
color = ERROR_COLOR if (row, col) == collision_cell else ARROW_COLOR
draw_arrow(surface, cx, cy, direction, color)
```

第一行等价于：

```python
if (row, col) == collision_cell:
    color = ERROR_COLOR
else:
    color = ARROW_COLOR
```

到时把 collision_cell 清为 None 后，下一次绘图会自动选择正常颜色。
不需要专门画一个青绿色箭头去覆盖红色，因为每帧都会清屏并重新绘制。
棋盘依然只保存方向和 None；显示颜色不参与路径判断。

## 5. 连续操作的处理规则

- 在红色反馈期间再次有效点击受阻箭头：再次扣一次，倒计时重设为 0.25 秒。
- 点击另一个受阻箭头：只显示最新一次碰撞，旧箭头恢复正常颜色。
- 变红期间点击可飞出的箭头：允许启动飞出，原碰撞计时继续，互不干扰。
- 飞出期间仍沿用第一批的限制：棋盘点击被忽略。
- 点击空格、棋盘外或右键：不会新建碰撞反馈，也不额外扣机会。
- 次数耗尽后：箭头颜色恢复，但失败文字和禁止点击的规则保持不变。

这些选择让本批只需要一个格子坐标和一个倒计时，适合当前阶段阅读。
